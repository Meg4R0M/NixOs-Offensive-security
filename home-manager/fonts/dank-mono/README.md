# Dank Mono (police payante)

Dépose ici tes fichiers `.otf`/`.ttf` achetés sur https://philpl.gumroad.com/l/dank-mono :

```
DankMono-Regular.otf
DankMono-Italic.otf      # l'italique cursive (la signature de la police)
DankMono-Bold.otf
DankMono-BoldItalic.otf  # si fourni
```

Puis `git add` + on branche le module `dank-mono.nix` (police monospace partout :
Stylix + wezterm + alacritty + kitty), avec repli Nerd Font pour les icônes.
